# 信息工程专业综合实验 2026

本仓库主要保存课程实验的 Python 代码。

- `experiment3_python`：DPCM 信源编解码、AES-128-CBC 加解密、汉明(7,4)信道编解码完整流程。
- `experiment4_network`：在实验三算法基础上完成 TCP 语音传输，可在 Windows 和 Firefly RK3399 Ubuntu 上运行。

- [experiment5_system](experiment5_system/README.md)：实验五完整语音处理与安全网络通信系统，包含采集、加噪、编解码、加密认证、滤波和质量评价。

请分别进入对应目录阅读 README 并安装依赖。
