## 原始语音的完整链路软件验证

本地验证使用实验一原始录音（个人录音未上传到公开仓库）：16000 Hz、单声道、16 bit、80000 样本、5 秒。

实际流程：幅值乘 0.75 → 5000 Hz/幅值 0.2 正弦加噪 → DPCM8 → AES-CBC/HMAC → Hamming(7,4) → 本机 TCP 软件传输 → 汉明译码 → 认证解密 → DPCM 解码 → 129 tap、300～3400 Hz FIR → 保存和评价。

实际结果：79 帧、80000 样本，两端摘要均为 `complete`；应用层音频消息字节总数为 170244，不包含全部控制消息及 TCP/IP 开销。

本次录音的指标：

| 比较对象 | MSE | SNR |
| --- | --- | --- |
| 滤波前解码语音与干净参考 | 0.02028470 | -1.81 dB |
| 最终语音与干净参考，补偿 64 样本延迟 | 0.00511741 | 4.18 dB |
| 最终语音与同 FIR 处理的干净参考 | 0.00000527 | 29.45 dB |

这些指标来自本次固定录音，不代表老师规定的合格线。带通滤波同时会去掉原录音频带外的有用分量，因此“同滤波参考”指标不能代替与原始干净参考的指标；两种均保留。完整运行文件保留在本地交付包中，公开仓库保留本页汇总和 `validation/unit_tests.log`，不上传个人录音及生成文件。接收滤波结果保存与原输入相同样本数，不补发 FIR 尾部，延迟对齐比较使用前后对应的 79936 个样本。
